# Bug Reportados:

## B001: Frete cobrado para subtotal exatamente igual a R$ 200,00

### Informações:
Campo                        | Valor                                                  |
---------------------------- |--------------------------------------------------------|
ID                           | BUG-001                                                |
Ambiente                     | https://verzel-store.qa-test-verzel-store.workers.dev/ |
Data da Execução             | 07/10/2026                                             |
Navegador                    | Google Chrome                                          |
Sistema Operacional          | Windows 10                                             |
Critério de Aceite associado | CA06                                                   |
Cenário associado            | CA06.1 - Conceder frete grátis para subtotal de R$ 200,00 |
Funcionalidade               | Frete grátis por valor mínimo do subtotal              |
Severidade                   | Alta                                                   |
Prioridade                   | Alta                                                   |
Status                       | Aberto                                                 |

### Descrição:

O sistema cobra R$ 19,90 de frete quando o subtotal do carrinho é exatamente R$ 200,00, contrariando o critério de aceite que estabelece frete grátis para compras com subtotal maior ou igual a R$ 200,00.

### Pré-condições

1 - Usuário está na página de produtos.

### Passos para reproduzir:

1 - Adicionar 2 unidades do produto "Mochila Urbana 20L" ao carrinho.

2 - Acessar o carrinho.

3 - Verificar o subtotal do carrinho.

4 - Verificar o valor do frete.

### Resultado esperado:

O sistema deve conceder frete grátis quando o subtotal do carrinho for exatamente R$ 200,00.

### Resultado obtido:

O sistema cobrou R$ 19,90 de frete mesmo com o subtotal do carrinho exatamente igual a R$ 200,00.
